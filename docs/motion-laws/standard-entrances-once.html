Rare tools and AI clichés

Standard entrances, once

Word-rise, count-up and zoom-fade each get one use per film.

Takeaways

  • One word-rise line per film.
  • One zoom-fade.
  • One count-up, for a number that matters.
  • Replace the rest with a swap, a mask or a cut.

What it means

These are the moves everyone reaches for. Each is fine once, in the place it earns its keep, and a tell when it is everywhere. So each gets a budget of one, and the rest of the film uses swaps, masks, splits and cuts on the beat.

In a RasanAI film

The cliche-* checks count them: one word-rise line, one zoom-fade entrance, one count-up for a real hero number such as social proof. Everything else is a swap in place, a mask wipe, an object splitting a word, a stepped pop or a hard cut.
