Scenes and rhythm

Dense, then sparse

Follow a crowded moment with an empty one; a long run of one kind needs a reason.

Takeaways

  • Alternate on purpose.
  • A long uniform run is flagged for review, not rejected.
  • A relentless passage is allowed when the story wants it.

What it means

Contrast is what makes each scene read. A collage lands because the single line before it was quiet; the quiet line lands because of the collage. A long run of dense beats, or of sparse ones, flattens into a texture unless the story wants exactly that.

In a RasanAI film

Every beat declares its density. The engine warns on a long run of one kind and a person decides whether it is deliberate. No dense-to-sparse ratio is fixed; the test is whether the viewer gets a breath and a contrast. See An intensity map.

Origins and sources

RasanAI launch grammar, studied from real launch films. An engine rule, not an academic law. No published source gives a dense-to-sparse ratio, so none is claimed.

Evidence: Single practitioner, with an engine default.
