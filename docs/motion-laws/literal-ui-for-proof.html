Type and image

Literal UI for proof, abstract UI for feeling

Use exact interface states when you claim a capability; use abstraction when you sell a sensation.

Takeaways

  • Proof: exact labels, figures and order.
  • Feeling: shape, colour and texture are enough.
  • An abstract shot never counts as evidence.
  • Keep the product's truth as the anchor inside a decorative world.

What it means

Two jobs, two treatments. A proof shot has to be accurate: the real labels, the real figures, the real order of events. A feeling shot can abstract the interface into shape, colour and texture to express what using it is like. The mistake is letting an abstract shot stand in as evidence that a capability exists.

In a RasanAI film

Every shot is classed as proof or metaphor. Proof shots use recreated, approved states and stay legible. Metaphor shots are free to abstract and are never counted as the first proof or the core job demo. Explicitly labelled future concepts may depict behaviour that does not exist yet.

Origins and sources

Studios split the two on purpose: one case study insists on exact interface text and figures, another abstracts the interface to express a listening benefit.

Evidence: Studio practice.

  • Liandan AI Studio, BGI Genpilot: interface text, clicks and figures built deterministically
  • Oddfellows, Spotify Premium: tactile 3D and abstracted UI
  • Ordinary Folk, Webflow Ecommerce: the actual UI stays focal
