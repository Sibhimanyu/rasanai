## Intake contract for a chosen reference

Record source URL, file path, commit or file/blob digest, review date, actual applicable license evidence, separate media/font/model rights, allowed adaptation mode, destination symbol, supported runtime/version, applicability/exclusions, and scoped rule IDs. Link any required notices. A reference pointer is not a dependency declaration.

Prefer original RasanAI glue around existing helpers. For unverified/restricted copying, keep original analysis and ideas only under the project's current policy. Do not represent a source-reported timing, README claim, license badge or star count as measured RasanAI evidence. Product references and studio case studies guide communication; they do not authorize copying source art or scripts.

## Selection order

Existing RasanAI implementation -> smallest compatible primitive -> narrowly selected licensed adaptation -> optional adapter with a real unmet need. A new library must explain the required capability it adds and the maintenance/permission/runtime cost. No plan requires installing every row.
