## 2. Four distinctions that must not blur

1. **MotionVideo: website MIT vs paid skill pack.** MIT covers only the site source. The skill pack, name and logomark are proprietary, sold under https://motionvideo.xyz/terms. RasanAI takes nothing from the pack.
2. **Remotion framework vs Remocn MIT components.** Remotion uses the custom Remotion License (free by entity size; Company License above; no sublicensing derivatives). Remocn and Remocn Studio are MIT but depend on Remotion, so their MIT grants no Remotion rights. RasanAI ships neither; the `remotion` adapter is opt-in with the licence note shown.
3. **GSAP Standard vs RasanAI MIT.** RasanAI's code is MIT (root LICENSE, Sibhimanyu 2026). Vendored GSAP and plugins are GreenSock Standard License, headers retained, not relicensed by our MIT. Redistributors keep GSAP under its own terms.
4. **Rive authoring/export vs open runtime.** rive-wasm is MIT and the pricing page advertises MIT runtimes with no runtime fees. The editor and its exports are SaaS with tier terms (free exports carry a splash screen). Adapter off by default.

## 3. Rules for Motion Studio code

- Catalog items carry `origin: original|reused-rasan`, `license: RasanAI MIT`, `credit: ""` (contract B). If an item is ever derived from a permissive source, set `credit`, add a section to SOURCES.md and a `third_party/<name>/` folder per INTAKE.md.
- Reference analysis (contract A) transfers rhythm and mechanics only; never logos, footage, unlicensed audio, verbatim copy.
- Adapters (openfilm, remotion, rive) default off and print the licence status from this ledger.
