# Dark tech keynote

A software launch where the interface is the star: near-black stage, hairline grid, one accent, snap-grid motion.

A reference for the design desk to blend one or two traits from, never a preset that replaces the film's bespoke system. Never cite it as the whole look; the signature features below are what a blend must keep if it names this style.

## Essence, and what it is not

A keynote-grade film for software. There is no physical product; the protagonist is the interface (a cursor, windows, notifications, tiles, one giant number) on a dark stage lit by soft cool light. Defined by precision: every element snaps to a grid, every move lands on a beat, one accent is reserved for the thing that matters.

Not: a glass product render, a real screencast, a hologram HUD, or a chart film.

## Materials

- Near-black base with a radial lift at the upper centre, one big cool glow at single-digit opacity, a corner vignette, a hairline grid (white about 3 percent, every 4th line about 6 percent) on a 48 px module; no grain.
- Original UI kit drawn in code: rounded windows with no OS chrome, notification cards, file icons, list rows, badges, tiles; three raised dark surface steps, 1 px border, 1 px inner top highlight, soft shadow.
- 2.5D camera with depth; light is the reveal tool (only lit pixels turn on).

## Colour logic

- A cool neutral ladder only (near-black, three surface steps, three greys), slightly blue never warm.
- One saturated accent with its own glow, reserved for what the product is or does; if two things are accent-coloured, one is wrong.
- A problem colour (usually red) exists only while the problem exists and never returns after the turn.
- Secondary hues only as desaturated category codes in motion.

## Type

- Neo-grotesk for UI and headlines, a tight display weight for giant numbers (about -4.5 percent tracking), a mono for labels and filenames.
- One line per screen; the big number gets its own screen with no caption over it.
- Captions are a UI toast (dark translucent pill, 1 px border, small accent dot).

## Motion

- On ones, precision not craft; moves start a beat early and land on it; fast-out easing with one small overshoot then settle; no floaty drift.
- Spawns are short and typed per element kind (drop, fling, slide, pop, 0.2 to 0.3 s); flights follow curved paths; disappearing is designed, never a plain fade.
- The stage and grid never move on their own; only the camera moves them.

## Camera grammar

- Locked extreme close-up on a tiny UI element, continuous log-space pull-back for accumulation, push-in through a frozen frame, whip pull-out for cause and effect, dive into a counter with a match cut, half-second insert storms for overload, lateral track across a UI plane, top-down plan over the grid, return to an earlier framing as a rhyme.
- Transitions are UI expand or collapse: an interface element grows into the frame or the frame collapses into one; no fades or blank frames.

## Signature features

Checkable traits; the frame juror and the critic look for each by name when a system claims this style.

1. Near-black stage with a hairline grid on a fixed module and a soft off-centre glow.
2. Exactly one accent colour, spent only on the protagonist element, the call to action and the key number.
3. Every move lands on the grid and on a beat, with at most one small overshoot.
4. Shot changes are UI element expand or collapse, never fades.
5. The giant number sits alone on its own screen with no caption over it.

## When to use

- SaaS, developer tools and AI-product launches where the product is an interface and the story is one decisive action.
- Anything needing a hero number or a before/after of disorder to order.

Avoid when: Physical products, warm or crafted brands, films whose product UI must be shown exactly as it really looks (use the real-UI route instead).
