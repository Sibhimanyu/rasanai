# Sovra.fm (Video-75914): breakdown

Sovra.fm launch film, 52 s, 16:9: an AI radio station. Almost entirely one dark ground lit by purple colour glow and light sweeps; small crisp type; no stepped motion. Analysed only (owner-supplied reference), never redistributed. Third reference beside Minase (stepped, white, collage) and Kinso (coral gradient, orb): it proves a launch film can be dark, smooth and small-typed if it is lit and always moving.

## What it does (the moves)

- **Copy becomes a literal visual metaphor.** "Same songs / Same feeds / Same loops": a pill grows into nested loop rings. "Your energy" becomes a glow bloom.
- **The cursor is used for real product actions** several times (clicking Create, uploading a photo, removing Spotify). It is never a highlight gimmick. Rare, story-motivated, done well.
- **The product flow as a mini demo**: prompt typed, Create, progress ring 11% to 100%, then the result (album art with a vinyl sliding out, "Original tracks").
- **A product character**: a DJ orb with eyes, with labelled gradient ribbons (Talking / Reacting / Flowing) as a local motif that bookends the middle.
- **Reading-guide line lighting**: "You've been listening to music wrong" lights up line by line, dim to bright.
- **A light trace running along a UI card's border** (the prompt box); a particle burst on a button press (one use, tied to an action, not atmosphere).
- **Slot list** ("Instant / Original / Hyped"), the same move as Minase.
- **End**: the logo plus a typed tagline swap, "Type it -> Stream it".

Scene types in one film: ribbon intro, type + product art, line-lighting type, UI card stack, UI list, metaphor diagram, turn slate, typed-prompt demo, result object, product character, upload demo, glow-bloom word, icon swap, small line, slot list, logo end. No scene type repeats back to back.

## What to take

- Atmosphere can be light, not only a ground colour: moving colour glow, light sweeps and blooms change across beats on one dark ground.
- A film is allowed to be smooth and crisp. Stepped and flicker sections (Minase) are a tool for energy, not a requirement.
- Small type is fine when the frame is lit and something moves every second.
- Real product actions get the cursor; the cursor never explains a word.
